# HTML Booking Sheet on Illustrated Background

## Goal

Use the supplied blank-banner A4 artwork as the booking-sheet background, while rendering the confirmation title, booking fields, details table, summary, conditions, and decorative icons as editable HTML/CSS content on top.

## Visual source

- Background asset: the supplied image with the empty green title banner, 1055 × 1491 px.
- Reference asset: the supplied completed example, used only to match geometry, typography, spacing, icon style, and content hierarchy.
- The background already contains the Lá Đỏ branding, phone/address row, landscape artwork, botanical borders, blank title banner, and closing footer. These parts are not duplicated in HTML.

## Composition architecture

- Keep the existing editor sidebar and form data model.
- Render `#page` as a fixed A4-ratio composition with a full-size local background image.
- Add a semantic `.sheet-content` layer positioned over the background using normalized percentage coordinates based on 1055 × 1491.
- Organize the HTML overlay into `title`, `intro`, `booking-information`, `details`, `summary`, and `conditions` regions.
- Use inline SVG icons generated by JavaScript from a small local icon map. No icon font or runtime icon CDN is required, so PNG/PDF capture remains deterministic.

## HTML-rendered regions

- Title banner: `BOOKING CONFIRMATION` centered inside the green banner already present in the background.
- Intro: `Dear Ms/Mr, {guest}` plus the two English confirmation sentences.
- Booking information: a two-column, three-row panel for guest name, number of nights, check-in/out dates, and check-in/out times. Each row has a themed SVG icon, baked-style label, and bold value.
- Details: section heading with building SVG icon and a responsive eight-column table matching the reference. Room rows are created from the editor data; guest list and room type preserve line breaks.
- Summary: total cell and deposit/payment cell with circular total icon and wallet icon. Deposit copy is formatted as `Customer has deposited {amount}`.
- Conditions: section heading with clipboard SVG icon, then included-services and cancellation-policy rows. Services render as bullet lines; policy renders as plain text.
- Footer: use only the footer artwork already present in the background image.

## Icon system

Create a local `icon(name, className)` helper returning accessible inline SVG with `currentColor` strokes and `aria-hidden="true"`. The icon map covers `user-badge`, `user`, `moon`, `calendar`, `clock`, `building`, `total`, `wallet`, `clipboard`, `bell`, and `shield`.

## Data behavior

- English is the active preview language for this version; baked background copy remains untouched.
- Guest, dates, times, nights, room rows, total, deposit, services, and policy update from existing form controls.
- Dates display in English long form, for example `June 3, 2026`.
- Room rate values use comma grouping; guest counts display as `{count} adults`.
- Add/remove room controls remain available. The table body is clipped to the reserved background region if more rows are entered than visually fit.
- User-entered content is HTML-escaped before insertion into markup.

## Responsive and export behavior

- The page keeps a 1055:1491 aspect ratio and scales as one composition in the existing preview/mobile flow.
- Overlay typography and spacing use percentages, `clamp()`, and region-level grid layouts so the HTML aligns with the fixed artwork at desktop and mobile sizes.
- Export captures the untransformed A4 composition so mobile zoom does not reduce PNG/PDF output.

## Scope boundaries

- Do not recreate the top logo, contact details, botanical artwork, or footer in HTML.
- Do not use the completed reference image as the production background.
- Keep the current sidebar labels and export actions unless a selector must be updated for the new content layer.

## Verification

- Verify background #1 is loaded and completed reference text is not baked into the production asset.
- Verify title, intro, information panel, table, summary, conditions, and inline SVG icons render without duplicate old-template markup.
- Change every form field and verify the matching HTML region updates.
- Add and remove rooms and verify table alignment and total calculation.
- Verify desktop/mobile aspect ratio and PNG/PDF output.
